# 9Lives10Hearts — v1.5.0

Хардкорный Minecraft-плагин: смерть отнимает сердце; после потери последнего сердца игрок выбывает из выживания. Поддерживаются режимы `hard` и `immortal`, SQLite, головы-сердца, проклятые головы и восстановление жизней.

## Версии и совместимость

Один JAR собирается с Java 17 bytecode (`--release 17`), против Paper API 1.20.1 по умолчанию. Применяется только публичный Bukkit API: атрибут максимального здоровья (`GENERIC_MAX_HEALTH` / `MAX_HEALTH`) и эффект тошноты (`CONFUSION` / `NAUSEA`) определяются по доступному имени. Текстуры голов применяются через Bukkit PlayerProfile, без NMS и Paper-only типов в коде.

| Линейка сервера | Java для сервера | Статус |
| --- | --- | --- |
| Paper/Spigot 1.20.1–1.20.4 | 17+ | Целевая совместимость; CI компилирует Paper API 1.20.1 |
| Paper/Spigot 1.20.5–1.21.11 | 21+ | Целевая совместимость; CI компилирует Paper API 1.21.11 |
| Paper 26.1.x–26.2 | 25+ | Целевая совместимость; CI компилирует Paper API 26.2 |
| Paper 26.3 (предварительные сборки) | 25+ | Не заявляется: необходимы отдельные тесты после стабильного релиза |

**Важно:** успешная компиляция против нескольких API — не полноценный runtime-тест каждого сервера. До проверки на конкретном Paper/Spigot-билде совместимость остаётся целевой. Folia не поддерживается: здесь используется обычный Bukkit scheduler, без region/entity scheduler. Версия `api-version: '1.20'` в `plugin.yml` намеренно минимальная — повышение до 26.2 запретило бы загрузку на старых серверах.

## Установка

1. Соберите `./gradlew clean build` на JDK 17 или новее, либо скачайте готовый артефакт успешного CI.
2. Установите **`build/libs/9lives10hearts-1.5.0.jar`** в `plugins/`. Не используйте `*-unshaded.jar`: только основной JAR содержит SQLite JDBC.
3. Перезапустите сервер. Конфигурация находится в `plugins/9lives10hearts/config.yml`, тексты — в `lang.yml`, данные — в `data.db`.
4. Сделайте резервную копию `data.db` перед обновлением с версии 1.4.x. Схема данных не изменялась.

Для проверки совместимости с выбранным API: `./gradlew clean build -PpaperApiVersion=1.21.11-R0.1-SNAPSHOT` или `-PpaperApiVersion=26.2.build.124-stable` (для последнего нужен JDK 25). CI выполняет сборку с API 1.20.1 / 1.21.11 / 26.2 и проверяет, что SQLite входит в JAR и классы плагина имеют формат Java 17.

## Механики и конфигурация

- `hearts.default` — стартовое число сердец, `hearts.max` — верхний предел.
- `hearts.loss-after-death` — число бесплатных смертей до потери сердец.
- `gamemode: hard` — 0 сердец означает выбывание; `immortal` — последнее сердце не теряется.
- `on-zero-hearts.commands` — команды консоли при 0 сердец, поддерживается `{player}`. По умолчанию используется spectator; например, `gamemode spectator {player}`.
- `heart-recovery.totem` — специальный тотем; `heart-recovery.eat` — еда для восстановления сердечка.
- `head-heart` — шанс выпадения головы, опция дропа только в PvP, свой base64 текстуры и CustomModelData; `head-heart.cursed` — отдельные настройки проклятой головы.
- Цвета сообщений поддерживают `&#RRGGBB` и `&x&R&R&G&G&B&B`.

## Команды

| Команда | Назначение |
| --- | --- |
| `/9l set <player> <number>` | Установить сердца |
| `/9l add <player> <number>` | Добавить сердца |
| `/9l remove <player> <number>` | Отнять сердца |
| `/9l look <player>` | Посмотреть сердца |
| `/9l gift <player>` | Передать одно сердце |
| `/9l resurrect <player> <number>` | Воскресить игрока |
| `/9l totem` | Получить уникальный тотем |
| `/9l reload` | Перезагрузить конфиги |

Права: `9l.set`, `9l.add`, `9l.remove`, `9l.look`, `9l.gift`, `9l.resurrect`, `9l.totem`, `9l.reload`.
