# 9Lives10Hearts (v1.4.x)

**9Lives10Hearts** — хардкорный Minecraft-плагин, где каждая смерть имеет цену.
У игрока есть ограниченный запас сердец: умер — потерял сердце. Закончились сердца — выбываешь из выживания.

Плагин рассчитан на Paper/Spigot 1.20.1+, Java 17.

---

## Что изменилось по сравнению со старым описанием

Актуальная версия плагина (ветка 1.4.x) получила расширенную механику:

- гибкая настройка лимитов сердец (`default`, `max`);
- счётчик смертей и параметр `loss-after-death` ("бесплатные" смерти без потери сердца);
- настраиваемые команды при 0 сердец (`on-zero-hearts.commands`), а не только перевод в GM3;
- улучшенная система дропа "сердечных голов":
  - шанс дропа,
  - опция дропа только от PvP-убийств,
  - отдельная **проклятая голова** с собственным шансом и штрафом по сердцам;
- хранение сердец и смертей в SQLite (`plugins/9lives10hearts/data.db`);
- поддержка hex-цветов в форматах `&#RRGGBB` и `&x&R&R&G&G&B&B`.

## Режимы игры

### `hard`
Классический режим: при потере последнего сердца игрок считается "выбывшим".
По умолчанию выполняется перевод в spectator, но это поведение можно заменить своими командами через `on-zero-hearts.commands`.

### `immortal`
Режим "почти бессмертия": игрок теряет сердца, но последнее (1) сердце не теряется.

## Команды

Базовая команда: `/9l <subcommand>`

- `/9l set <player> <number>` — установить количество сердец;
- `/9l add <player> <number>` — добавить сердца;
- `/9l remove <player> <number>` — убрать сердца;
- `/9l look <player>` — посмотреть количество сердец;
- `/9l gift <player>` — передать 1 сердце другому игроку (только от имени игрока);
- `/9l resurrect <player> <number>` — воскресить игрока из spectator с указанным числом сердец;
- `/9l totem` — выдать уникальный тотем восстановления;
- `/9l reload` — перезагрузить `config.yml` и `lang.yml`.

## Ключевые настройки `config.yml`

```yml
gamemode: hard

hearts:
  default: 10
  max: 10
  loss-after-death: 0

on-zero-hearts:
  commands:
    - "gamemode {player} spectator"

heart-recovery:
  totem:
    enabled: true
  eat:
    enabled: true
    food: "ENCHANTED_GOLDEN_APPLE"

head-heart:
  enabled: true
  only-player-kill: true
  drop-chance: 1.00
  cursed:
    enabled: true
    chance: 0.05
    amount-heart: 1
```

## Восстановление сердец

Плагин поддерживает несколько источников восстановления:

- уникальный тотем (`/9l totem`) — спасает при срабатывании resurrection-события;
- настраиваемая еда (по умолчанию: зачарованное золотое яблоко);
- "сердечные головы", выпадающие при смерти игрока.

Дополнительно можно включить "проклятую голову", которая выглядит как полезный предмет, но отнимает сердца при использовании.

---

## Для серверов с сюжетом и политикой

9Lives10Hearts отлично подходит для:

- анархии с экономикой риска;
- RPG/лор-серверов, где смерть — это часть истории;
- приватных сезонов с дипломатией, предательствами и воскрешениями по правилам сервера.

Это плагин не про "лишний индикатор HP". Он про ставки, страх смерти и цену каждого решения.
